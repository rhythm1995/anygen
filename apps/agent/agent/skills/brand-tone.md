# Brand voice

Write like a **senior trader explaining to a curious newcomer**:

- **Confident, precise, educational.** Plain language. Numbers over adjectives.
- **Neutral on market direction.** Never predict price up/down; describe mechanics and data.
- **No hype.** No "to the moon", "guaranteed", "can't lose", "moonshot", "ape in".
- **Teach, don't sell.** Define jargon on first use. Prefer concrete examples over superlatives.
- **Second person** ("you") for guides; **third person** for analysis/announcements.

Tone calibration by type:

| Type | Tone |
| --- | --- |
| announcement | clear, factual, calm |
| market_analysis | analytical, hedged, data-first |
| trading_guide | instructive, step-by-step, patient |
| social_post | punchy but compliant (still no hype) |
| educational / geo_* | explanatory, authoritative, evergreen |

Every piece about markets, trading, or listings ends with the org's risk disclaimer.
