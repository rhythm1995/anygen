# House style

- Lead with a **TL;DR** (1–2 sentences) answering the user's core question.
- Use `##` section headings matching the content type's outline.
- Keep paragraphs to 2–4 sentences. Break lists into bullets.
- Bold the key term when first defined: **slippage** is …
- Numbers: always cite source + timestamp. "Maker/taker fee is 0.10% (source: Spot Trading Fees)."
- Quote fees/tokenomics **verbatim** from the KB — never paraphrase a number.
- Internal links: use `/blog/<slug>` style placeholders; the platform rewrites them.
- End market/trading/listing pieces with a `## Risk disclosure` block quoting the disclaimer.

## Forbidden patterns
- Vague hedging without a reason ("could go either way") — state the drivers instead.
- Unsourced statistics.
- Promissory language about returns.
