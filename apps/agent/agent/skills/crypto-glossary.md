# Glossary (canonical definitions)

Use these exact definitions when a term is introduced. Call `query_kb` for the
live org glossary; below are sensible defaults if not overridden.

- **CEX** — Centralized Exchange. A platform operated by a company that matches orders.
- **DEX** — Decentralized Exchange. On-chain order matching via smart contracts.
- **AMM** — Automated Market Maker. Sets price algorithmically from a liquidity pool.
- **Slippage** — The difference between the expected and executed trade price; worse in low-liquidity pools.
- **Liquidity pool** — Tokens locked in a smart contract that enable trading on a DEX.
- **APY** — Annual Percentage Yield. The yearly return including compounding; variable, not guaranteed.
- **Maker / Taker** — Maker adds liquidity (limit order), Taker removes it (market order).
- **Spot trading** — Buying/selling an asset for immediate settlement.
- **Self-custody** — Holding assets in a wallet only you control (not on an exchange).

When the exchange has its own product terms (e.g. the HELIX token), always pull the
definition from `query_kb` and cite it.
